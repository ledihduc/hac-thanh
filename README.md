# Nông Sản Địa Phương — UI demo

Website tĩnh gồm hai URL thương hiệu: `index.html` cho Quế Food và `huong-rung.html` cho Hương Rừng. Hai trang dùng thẻ sản phẩm có ảnh chờ, nút mua hàng và hộp thoại hỗ trợ COD hoặc mã QR thử nghiệm có hạn 5 phút.

## Chạy local

```bash
python3 -m http.server 8080
```

Mở `http://localhost:8080`.
